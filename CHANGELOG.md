# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v26.3.3-mc26.3.x] - 2026-11-12

### Added

- Vanilla's calcite, basalt, and end stone blocks now have stair, slab, and wall variants

### Changed

- Cracked, chiseled and mossy variants can now properly be obtained via crafting and smelting respectively

### Removed

- Cracked and mossy variants are no longer available in the stonecutter

## [v26.3.2-mc26.3.x] - 2026-11-11

### Added

- Add missing crafting and smelting recipes

### Changed

- Rework stone variant registration around block set families
- Stone variant recipes are now generated in line with vanilla block families
- The previously missing vanilla stairs, slabs, and walls are now found in the mod's own creative tab

## [v26.3.1-mc26.3.x] - 2026-09-27

### Changed

- Add new textures for all tuff blocks thanks to the
  amazing [leftchaotix](https://www.curseforge.com/members/leftchaotix/projects)

## [v26.3.0-mc26.3.x] - 2026-09-26

### Changed

- Update to Minecraft 26.3.x
